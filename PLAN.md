# Tail Tally roadmap

The app is now native SwiftUI for iPhone (iOS 17+). The Flutter/Android implementation has been retired.

Implemented: household and pet setup, weekly routines, daily completion workflow, history, optional reminders, JSON backup/restore compatibility, CSV export, retention, deletion, native build gates, and App Store assets.

Future work: profile photos, editing routine schedules in place, automatic SQLite migration for existing Flutter installs, and broader physical-device/accessibility coverage.

Cloud sync, veterinary diagnosis/treatment, emergency monitoring, GPS, marketplaces, and smart-feeder automation remain outside the current scope.
