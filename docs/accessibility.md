# Accessibility

The native iPhone UI uses SwiftUI navigation, lists, forms, labeled controls, semantic text styles, and system colors. Timeline action groups switch to a vertical arrangement when horizontal space is insufficient. Status is conveyed by text and symbols, not color alone. Icon actions include text labels, and pet filters use native pickers.

Before release, verify with VoiceOver and Accessibility Inspector on iPhone:

- All four tabs, pet/routine creation, completion/undo, and history editing
- Settings, permission denial, import/export, and destructive confirmations
- Maximum accessibility text size, Increase Contrast, light/dark modes
- Keyboard dismissal, small-screen scrolling, and notification opening

Simulator captures validate standard-size layout; they do not substitute for a full VoiceOver or physical-device audit.
